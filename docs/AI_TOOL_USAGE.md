# AI 工具使用说明

## 使用工具

- Codex：需求拆解、产品结构、数据模型、Vue/TypeScript 实现、指标逻辑、测试和文档整理。
- GitHub 开源项目：Vue、Vite、Ant Design Vue、Apache ECharts、Vue ECharts、Pinia、Lucide。

## 关键提示方向

1. 将面试题拆解为活动效果、生成稳定性、内容审核、设备状态四类运营信号。
2. 为每个 KPI 定义公式、数据来源、异常阈值和运营动作，避免图表只展示不决策。
3. 设计 1440×900 桌面端运营台，并明确移动端的单列降级方式。
4. 用固定种子的模拟数据覆盖正常、预警、严重异常和空数据状态。
5. 补充审核三态、设备维度指标、异常明细分布、多点位筛选、小时趋势和 CSV 导出。
6. 对筛选、环比、异常抽屉、GitHub Pages 路径和响应式布局进行验收。

## 主要人工决策

- 选择第 3 题，优先保证交付完整度和演示稳定性。
- 采用纯前端静态架构，不把评审风险放在外部 API、跨域和密钥上。
- 将异常中心设计为“指标 → 原因 → 动作”的闭环，而不是装饰性红点。
- 使用浅色企业运营台和深色顶部导航，避免廉价的紫色渐变和纯数据大屏风格。
- 对所有演示数据标注为演示快照，避免将模拟数据伪装成实时生产数据。
- 保持扫码/分享 KPI 以成功生成会话为分母，用来衡量生成成功后的承接与传播效率，并在文档和页面口径中明确说明。
